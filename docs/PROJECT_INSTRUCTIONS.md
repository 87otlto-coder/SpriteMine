Start every development conversation by inspecting repo state, README, AGENTS.md, project status and roadmap. Implement incrementally, with small feature branches, tests, docs, PRs into main, and a separate `research/*` branch for experiments. Preferred stack: Python, PySide6, MesenCE, SQLite/JSON, optional C++. Research NESdev, MesenCE, FCEUX and captainsouthbird SMB3 disassembly; respect licenses. Communicate verified changes, gaps, risks and next steps clearly, without emojis. Milestones: ROM/CHR foundation; emulator feasibility; static UI; sprite inspector; animation exports; validated World 1-1 decoding; audio workbench; Windows release.
